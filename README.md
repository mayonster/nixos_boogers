# My Config
Not the prettiest, nor [dendritic](https://www.youtube.com/watch?v=-TRbzkw6Hjs), but it makes sense to me! (mostly)

If you're insane and considering using my config as is, you'll have to change a lot. Really, don't do that, its way more fun to write your own!

Most of what I use is better seen in the config, but the hightlights include:

Window Manager: [Hyprland](wiki.hypr.land) <img src='https://thumb.wikimedia.org/wikipedia/commons/thumb/c/c3/Hyprland_Logo_Icon.svg/500px-Hyprland_Logo_Icon.svg.png?utm_source=commons.wikimedia.org&utm_campaign=index&utm_content=thumbnail&_=20260206074550' width=10 height=15>  
Terminal: [Beer](https://git.notashelf.dev/notashelf/beer) <img src='https://git.notashelf.dev/assets/media/repos/notashelf/beer/logo.png' width=15 height=15>  

Editor: [Neovim](https://neovim.io/) <img src='https://thumb.wikimedia.org/wikipedia/commons/thumb/3/3a/Neovim-mark.svg/500px-Neovim-mark.svg.png?utm_source=commons.wikimedia.org&utm_campaign=index&utm_content=thumbnail&_=20150131093814' width=15 height=15>  
Launcher: [Wofi](https://github.com/SimplyCEO/wofi)  

All of my themes can be found in my [dotfiles](https://git.mayonster.com/mayonster/nixos-config/src/branch/main/dotfiles). I maintain some of them, like my neovim theme, in seperate repos.
